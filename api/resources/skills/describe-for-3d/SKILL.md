# Prompts that generate well in 3D

Image-to-3D models rebuild the object they see, so the picture must show one whole object clearly.

Rewrite the user's idea into a prompt that includes:
- **One subject**, fully in view, centred — "a single …".
- **A plain light background** — "isolated on a white background".
- **A three-quarter view** at eye level — shows front and side so the back can be inferred.
- **Simple, even lighting** — "soft studio lighting, no harsh shadows".
- **Materials and colours** if they matter — "matte red ceramic", "brushed steel".
- Leave out scenery, text, logos and other objects.

Example: "dragon" → "a single small cartoon dragon figurine, three-quarter view, standing, green scales with gold belly, soft studio lighting, isolated on a white background".

Show the user the rewritten prompt and ask before generating if they wanted something specific.
